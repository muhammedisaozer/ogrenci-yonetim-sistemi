# 🎓 Öğrenci Yönetim Sistemi (Student Management System)

Spring Boot, Spring Data JPA, Thymeleaf ve MySQL kullanılarak geliştirilmiş tam kapsamlı (Full-Stack) MVC öğrenci yönetim web uygulaması.

---

## 🚀 Özellikler

- **Tam CRUD Operasyonları:** Öğrenci ekleme, listeleme, güncelleme ve silme.
- **Dinamik Arama (Search):** JPQL tabanlı özel sorgu ile ad, soyad, e-posta veya bölüm bazlı filtreleme.
- **Form Doğrulama (Validation):** `spring-boot-starter-validation` ile veri bütünlüğü ve kullanıcı dostu hata bildirimleri.
- **Duyarlı Arayüz (Responsive UI):** Bootstrap 5 ve Thymeleaf şablon motoru ile temiz arayüz tasarımı.

---

## 🛠️ Kullanılan Teknolojiler

- **Backend:** Java 17+, Spring Boot 3 (Spring Web MVC, Spring Data JPA, Hibernate, Validation)
- **Frontend:** Thymeleaf, HTML5, CSS3, Bootstrap 5
- **Veritabanı:** MySQL
- **Derleme Aracı:** Maven
